## Why I Bought a Domain
I was scrolling the CompSoc discord #general channel as usual, and I noticed people talking about buying domains.

I have never bought a domain before as I thought it would be expensive to buy a "good" domain (whatever that means), however I overestimated how popular my name is.

So here I have kaiwen.wang, which I think is the best domain for me to have.

Thus, after paying the $3.12, I now have this for a year. I plan to pay for it every year for the rest of my life, so hopefully I iterate this website over time - even though my web dev days are past me.

## Website Design

I was very inspired by ex CompSoc 3rd and 4th year rep Tomas' [site](https://tomasmaillo.com/). And heavily relied on that to create the layout for the page and some features.

The colour palette is based of the Arc colour palette - possibly the best browser ever created, despite it now being no longer maintained :(

## How it was built

It is a React app styled with Tailwind, built with Vite with JavaScript and hosted for free on GitHub Pages. Posts, including this one, are Markdown files in a folder.

Claude was also heavily used, I don't think I've touched web dev for around a year.
