This site is intentionally small. One page, a handful of sections, a dark background and a few colours borrowed from a browser logo I like.

## Why so minimal

Every previous version of my site was more elaborate than the one before it, and every one of them I eventually found exhausting to maintain. So this time the rule was: nothing that does not earn its place.

## How it is built

It is a React app styled with Tailwind, built with Vite and hosted for free on GitHub Pages. Posts — including this one — are just **Markdown files** in a folder. Drop a new file in, and a link appears here automatically.

## The animations

There is motion, but it tries to stay quiet: sections fade in as you scroll, cards lift when you point at them, and a soft light follows the cursor. Nothing blinks, nothing demands attention.

That is the whole site. If you are reading this, the Markdown pipeline works.
